\section{Experiments}
\label{sec:experiments}

We evaluate the two paper-level contributions with matched physical skills and
policy-visible observations. C1 asks whether a heterogeneous team benefits from
explicit semantic responsibility. C2 asks when semantic reasoning should
re-enter while physical execution continues. Directive-Governed Actuator-Local
Execution in Section~III-C supports physical closure rather than defining a
third contribution; conveyor motion is a controlled physical condition.

\subsection{Experimental Setup and Protocol}
\label{sec:experiment_setup}

\noindent\textbf{Scenario and matched conditions.}
The simulation uses the heterogeneous conveyor workspace in
Figure~\ref{fig:scenario} with two Franka manipulators, suction actuators,
RGB-D observations, and public local skills. Task, scene, event, and random
seeds are paired across methods, while local tracking, grasp, motion, and
safety stacks remain fixed. The primary conditions are (C1) approximately
static physical state with no semantic event, (C2) continuous conveyor motion
with no semantic event, (C3) static state with sparse semantic events, and (C4)
continuous motion with the same sparse events. C2 is the physical-only
negative control: changing image observations and tracking error does not, by
itself, authorize semantic re-entry. C3 and C4 vary independent, sparsely
coupled, and tightly coupled obligation graphs and a small or medium true
affected fraction, separating physical difficulty from coordination effects.

\noindent\textbf{Events and ownership.}
Episodes label P0 physical-only dynamics, S1 exogenous scene disruption, S2
task update, and S3 verification/execution evidence. S1 scene facts route to
the Affordance Role, S2 task fields to the Planning Role, and S3 status
evidence to the Verification Role. Event detection and routing are scored
separately from semantic field ownership; Verification does not write task
goals, affordance fields, or assignments.

\noindent\textbf{Compared methods.}
B1 is a monolithic central semantic coordinator with the same shared
information, validator, compiler, and physical stack, but without explicit
role-owned deltas. B2 gives each actuator a complete semantic replica and
rejects conflicting fields by a declared neutral rule. B3 receives the same
semantic event boundaries as Proposed but globally revalidates eligible active
and future obligations while remaining continuation-capable under local
guards. A\textsubscript{cap}, A\textsubscript{cont}, A\textsubscript{evid},
and A\textsubscript{event} are introduced only where their corresponding
mechanism is tested. The external comparator is reserved for the
architecture-neutral integrated comparison; its fairness conditions are stated
with that comparison.

\noindent\textbf{Evaluation.}
The main outcomes are task success rate, obligation completion, event recovery
success, makespan, and unaffected interruption rate. High-level semantic-call
count is a secondary efficiency outcome. Table~\ref{tab:role_shared_results}
diagnoses C1; Figure~\ref{fig:selective_reentry_results} diagnoses C2; and
Table~\ref{tab:mechanism_hardware_results} with
Figure~\ref{fig:integrated_execution_trace} reports integrated, conformance,
and hardware evidence. The main text retains invalid-proposal, capability,
scope, and stale-evidence diagnostics; compliance traces, detailed routing
confusion, failure categories, model costs, and local-control quantities are
supplementary. Proportions use Wilson intervals, and paired timing/count
differences use bootstrap intervals with medians and IQR for skewed measures.
Trial counts, seeds, and backend settings remain \textbf{OPEN / ***}.

\subsection{Semantic Event Discrimination and Selective Re-entry}
\label{sec:exp_multi_timescale}

\noindent\textbf{Physical-only negative control.}
The first C2 question is whether persistent physical change stays local. Under
C2/P0, Proposed is compared with A\textsubscript{event}, which treats every
debounced meaningful observation change, including conveyor motion, as a
semantic trigger. Figure~\ref{fig:selective_reentry_results}(a) reports the
false semantic-trigger rate, separating local visual adaptation from semantic
re-entry.

\noindent\textbf{Selective affected-scope re-entry.}
When an S1, S2, or S3 event is real, the question becomes what should
re-enter. Proposed and B3 receive identical event boundaries; the comparison
therefore isolates affected-scope reconsideration from event timing. Panel
(b) of Figure~\ref{fig:selective_reentry_results} reports affected coverage
and excess reconsideration across the dependency couplings and affected
fractions in C3/C4. B3 is a scope-control reference, not an independent event
detector.

\noindent\textbf{Physical continuity.}
Eligible unaffected directives should continue while the affected semantic
scope is processed. A\textsubscript{cont} holds active directives during the
semantic transaction, allowing the paired comparison to expose the cost of
losing selective continuation. Figure~\ref{fig:selective_reentry_results}
also reports event-to-commit latency and unaffected interruption in panels
(c)--(d). Any safety or local-guard stop is logged separately from semantic
interruption.

\noindent\textbf{Same-batch evidence compatibility.} We cross old completion
evidence with target replacement, obligation withdrawal, intended-effect
change, unrelated edit, no defining change, ambiguity, and failure in one
same-batch matrix. Proposed and A\textsubscript{evid} are compared using the
stale-completion acceptance and compatible-completion rejection quantities in
Table~\ref{tab:mechanism_hardware_results}(b). Rejecting all old evidence is
not a valid success criterion; this block closes the C2 conformance test
rather than defining a separate contribution.

\subsection{Integrated Dynamic and Real-Robot Validation}
\label{sec:exp_integrated}

\noindent\textbf{Integrated comparison.}
Do the mechanisms preserve architecture-neutral task behavior under static and
continuously dynamic conditions? Proposed, \emph{COHERENT-adapted}~\cite{liu2025coherent}, and B3
where feasible receive matched tasks, observations, event schedules, and local
skills. The adapted comparator preserves COHERENT's published centralized Task
Assigner and Proposal--Execution--Feedback--Adjustment loop, but is mapped to
the same Isaac observations, public skills, validators, and safety stack. It
does not receive role ownership, affected-set closure, directive lifecycle,
same-batch compatibility, or the P0 event gate, and is evaluated only with
neutral outcomes. Table~\ref{tab:mechanism_hardware_results}(a) reports task
success, obligation completion, event recovery, makespan, semantic-call count,
and unaffected interruption over C1--C4. The recovery chain is read as event
recognition/routing, semantic update handling, directive revision or valid
continuation, physical completion/recovery, and final task success.

\noindent\textbf{Hardware credibility slice.}
The physical team is two Franka manipulators and one vehicle-mounted/mobile
manipulator. H1 tests meaningful heterogeneous authorization and concurrent
execution. H2 combines continuous physical execution with one reproducible S1
or S3 event while an unrelated directive is locally eligible. Hardware does
not repeat the full baseline matrix; low-level control, tracking, navigation,
grasping, and safety remain supporting realization. Table~\ref{tab:mechanism_hardware_results}(c)
and Figure~\ref{fig:integrated_execution_trace}(b) report task outcome, event
recovery, response latency, unaffected interruption, and compliance quantities
as \textbf{***} placeholders. Physical failures are classified separately
from event recognition, semantic proposal, capability-grounding, affected-
scope, and stale-evidence failures.
