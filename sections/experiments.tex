\section{Experiments}
\label{sec:experiments}

We design the evaluation around the two paper-level contributions. C1 asks who
owns semantic responsibility in a heterogeneous team. C2 asks when semantic
reasoning should re-enter while physical execution continues. Directive-
Governed Actuator-Local Execution in Section~III-C is supporting realization
for physical closure, not a third contribution. Dynamic conveyor execution is
therefore a controlled physical condition, not a moving-target contribution.

\subsection{Experimental Setup and Protocol}
\label{sec:experiment_setup}

\noindent\textbf{Conditions and observations.}
The simulation uses the heterogeneous conveyor workspace in
Figure~\ref{fig:scenario} with two Franka manipulators, suction actuators,
RGB-D observations, and public local skills. We pair task, scene, event, and
random seeds across methods. The primary factorial is: (C1) approximately
static physical state with no semantic event; (C2) continuous conveyor motion
with no semantic event; (C3) static state with sparse semantic events; and
(C4) continuous motion with the same sparse events. C2 is the physical-only
negative control: changing image observations and tracking error does not, by
itself, authorize semantic re-entry. C3 and C4 use independent, sparsely
coupled, and tightly coupled obligation graphs with a small or medium true
affected fraction. Local tracking, grasp, motion, and safety stacks are held
fixed, so physical difficulty is scored separately from coordination effects.

The event schedule labels P0 physical-only dynamics, S1 exogenous scene
disruption, S2 task update, and S3 verification/execution evidence. S1 scene
facts are routed to the Affordance Role, S2 task fields to the Planning Role,
and S3 status evidence to the Verification Role. Event detection and routing
are measured separately from semantic field ownership; Verification does not
write task goals, affordance fields, or assignments.

\noindent\textbf{Methods.}
B1 is a monolithic central semantic coordinator with the same shared
information, validator, compiler, and physical stack, but without explicit
role-owned deltas. B2 gives each actuator a complete semantic replica and
uses a declared neutral conflict rule: conflicting fields are rejected rather
than resolved by Proposed's authority mechanism. B3 receives exactly the same
semantic event boundaries as Proposed but globally revalidates eligible active
and future obligations while remaining continuation-capable under local guards.
The external comparator is \emph{COHERENT-adapted}~\cite{liu2025coherent}.
It preserves COHERENT's published centralized Task Assigner and
Proposal--Execution--Feedback--Adjustment loop, but is adapted to the matched
Isaac observations, public skills, validators, and safety stack. It is used
only for architecture-neutral integrated outcomes; role-owner and
directive-origin metrics do not apply to it. The adapter is accepted only
after a reference-task interface check, and is rejected if the published PEFA
logic cannot be preserved fairly.

\noindent\textbf{Outcome and diagnostic metrics.}
Primary outcomes are task success rate, obligation completion percentage, event
recovery success rate, makespan, unaffected interruption rate, and high-level
semantic-call count. C1 diagnostics are invalid proposal rate, B2 replica
divergence, capability-invalid assignment rate, and feasible-assignment recall.
C2 diagnostics are affected coverage, excess reconsideration, false semantic
trigger rate under P0, event-to-commit latency, and unaffected interruption.
Same-batch conformance uses stale-completion acceptance and compatible-
completion rejection. Proportions will use Wilson intervals; paired timing and
count differences will use bootstrap intervals with medians and IQR for skewed
quantities. Trial counts, seeds, and backend settings remain \textbf{OPEN / ***}.

\subsection{Semantic Event Discrimination and Selective Re-entry}
\label{sec:exp_multi_timescale}

We test whether persistent physical change stays local and
whether true events cause only affected-scope reconsideration. Proposed and B3
share event boundaries; A\textsubscript{event} treats debounced meaningful
observation changes, including P0 motion, as semantic triggers; and
A\textsubscript{cont} holds active directives during semantic processing.
Figure~\ref{fig:selective_reentry_results} reserves four views: P0 false
semantic-trigger rate, affected coverage/excess scope, event-to-commit latency,
and unaffected interruption rate. S1, S2, and S3 events are stratified by
dependency coupling and affected fraction in C3/C4. This design distinguishes
continuous local physical adaptation from semantic re-entry without assuming
that an external method must fail. Because B3 receives the same event
boundaries by design, event-detection recall and recognition latency are scored
only for an exposed recognizer/router; B3 is a scope-control reference, not a
detector comparator.

\subsection{Integrated Dynamic and Real-Robot Validation}
\label{sec:exp_integrated}

We evaluate the complete chain
\(S^{\mathrm{sem}}\!\rightarrow c_v\!\rightarrow\kappa_v\!\rightarrow
y_i^{\mathrm{exec}}\!\rightarrow\mathbf e_k\!\rightarrow D_k\) under C1--C4.
Proposed, COHERENT-adapted, and B3 where feasible receive matched tasks,
observations, event schedules, and local skills. The architecture-neutral
comparison reports task success, obligation completion, event recovery,
makespan, semantic-call count, and unaffected interruption. The recovery chain
is scored as event recognition/routing, semantic update handling, directive
revision or valid continuation, physical completion/recovery, and final task
success. No external method is evaluated using role-owner or directive-origin
violations.

Figure~\ref{fig:integrated_execution_trace} aligns semantic versions, fixed
directive fields, local physical execution, event routing, dispositions, and
terminal outcomes. The trace is intended to reveal whether a semantic event
changes a directive by issuing a new commitment rather than mutating an active
one. The complete simulation and hardware quantities remain \textbf{***} until
trials exist.

\noindent\textbf{Hardware credibility slice.}
The physical team is two Franka manipulators and one vehicle-mounted/mobile
manipulator. H1 tests meaningful heterogeneous authorization and concurrent
execution. H2 combines continuous physical execution with one reproducible S1
or S3 event while an unrelated directive is locally eligible. Hardware does
not repeat the full baseline matrix, and low-level control, tracking,
navigation, grasping, and safety remain supporting realization. Table~\ref{tab:mechanism_hardware_results}(c)
reports task outcome, event recovery, response latency, unaffected interruption,
and compliance quantities as \textbf{***} placeholders. Physical failures are
classified separately from event recognition, semantic proposal,
capability-grounding, affected-scope, and stale-evidence failures.
