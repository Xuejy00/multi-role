\section{Experiments}
\label{sec:experiments}

The experiments evaluate whether role-shared semantic coordination improves
heterogeneous manipulation and whether event-scoped updates preserve valid
execution during adaptation.  All numerical entries in the current draft are
explicit placeholders pending the final runs and do not encode a measured
ranking.

\subsection{Experimental Setup}
\label{sec:experiment_setup}

The evaluation uses the Isaac conveyor workspace in Figure~\ref{fig:scenario},
with heterogeneous manipulators, static and moving targets, global visual
observations, and the common primitive skill library.  Every method uses the
same scene and task assets, physical controllers, local tracking and safety
stack, observation interface, and task-success criteria.  The evaluation
contains four conditions, denoted \texttt{C1}--\texttt{C4}, spanning static and
dynamic scenes with and without semantic events.  The events are \texttt{E1},
an online task update; \texttt{E2}, an external disturbance; and \texttt{E3},
an execution failure confirmed from physical evidence.  Execution-failure
trials use a stacked-object challenge in the static scene and a high-speed
conveyor challenge in the dynamic scene.  Task instances and scene
initializations are paired across methods.  Trial counts and other protocol
values remain \textbf{TBD} until the final runs are frozen.

The evaluation reports five metrics.  M1 is Task Success Rate, the fraction of
tasks completed according to the task-success criterion.  M2 is Subtask
Completion Rate, the fraction of primitive subtasks verified as completed.  M3
is Makespan, measured from the first dispatch until task completion.  M4 is
Event Response Time, measured from detection of a task-relevant event to the
next committed semantic update.  M5 is LLM Cost, reported using the same token
or call accounting for every method.  Failure Type Analysis is reported
separately as qualitative evidence and is not an additional metric.

\subsection{Comparison with Baselines}
\label{sec:baseline_comparison}

The comparison uses three baselines under the same scene, task, observation,
skill, and success protocols.  B1 is End-to-End LLM Skill Assignment and maps
the task and scene directly to global skill commands.  B2 is One-LLM-per-
Manipulator Skill Sequencing and gives each manipulator an independent skill
sequence without an authoritative joint plan.  B3 is COHERENT-adapted and
retains the coordination logic of COHERENT~\cite{liu2025coherent} while using
the common primitive execution interface.  Table~\ref{tab:main_comparison}
reports success rate, completion performance, and makespan across the static,
dynamic, and event-driven conditions.  The comparison is interpreted only
after the paired measurements are available.

\subsection{Ablation Study}
\label{sec:ablation}

The ablation study isolates the two method contributions.  A1 removes explicit
role sharing while retaining shared information, event handling, and the common
physical stack.  A2 retains the role structure but replaces selective
event-driven updates with global reconsideration of unfinished subtasks.

\subsection{Hardware Experiments}
\label{sec:hardware_experiments}

The hardware platform comprises two fixed Franka manipulators and one xArm
manipulator mounted on a mobile base in the conveyor workspace.  The planned
demonstration requires the heterogeneous team to execute concurrent primitive
commands while handling both an online task update and an external disturbance
introduced by a human.  It evaluates whether shared semantic reasoning can
revise the affected task scope while valid manipulator execution continues.
