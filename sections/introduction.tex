Heterogeneous multi-manipulator systems combine complementary workspaces,
end-effectors, sensing, and payload capabilities.  Open-language manipulation
tasks further require these embodiments to act concurrently while targets move,
the scene changes, or execution fails.  Physical state therefore evolves
continuously, whereas task-relevant semantic changes occur at discrete event
boundaries.  A direct vision-and-language to action mapping does not expose the
capability constraints, task dependencies, or responsibility interfaces needed
to coordinate this combination.

Large language and vision-language models provide semantic tools for interpreting
instructions, grounding objects and skills, and revising task state from
feedback~\cite{huang2023inner,liang2023code,rana2023sayplan}.  Their use in a
heterogeneous team still requires one consistent semantic representation that
can be read by multiple reasoning roles while local perception and control
continue at a higher rate.  Independent semantic decisions can otherwise assign
incompatible actions or obscure which information changed.  This motivates the
following question: how can semantic reasoning be organized so that a team
maintains shared task meaning, adapts only when a task-relevant event occurs, and
continues valid physical execution between events?

Figure~\ref{fig:scenario} grounds this question in the heterogeneous conveyor
workspace.  The physical scene illustrates the coexistence of complementary
manipulators, moving targets, visual observations, task updates, disturbances,
and execution failures.

\subsection{Our Method}

The proposed method maintains one role-shared semantic representation for the
current task, task dependencies, scene feasibility, assignments, and execution
status.  Affordance, Planning, and Verification Roles contribute complementary
information to this representation.  Task updates, external disturbances, and
execution failures trigger selective reconsideration, while valid physical
execution continues whenever the affected scope does not invalidate it.  The
resulting primitive commands are issued concurrently to compatible
manipulators and executed by their local skills.

The paper makes two contributions:
\begin{itemize}
    \item \textbf{Role-Shared Semantic Representation.}  A single semantic
    representation gives Affordance, Planning, and Verification Roles explicit
    information responsibilities for task decomposition, capability-aware
    assignment, and execution-effect assessment.

    \item \textbf{Selective Event-Scoped Reconsideration.}  Task updates,
    external disturbances, and execution failures identify a bounded scope for
    semantic revision, while compatible unaffected execution continues through
    manipulator-local skills between event boundaries.
\end{itemize}
