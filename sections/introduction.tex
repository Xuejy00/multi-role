\section{Introduction}
\label{sec:introduction}
\providecommand{\introchange}[1]{#1}
\providecommand{\structurechange}[1]{#1}
\providecommand{\localexecchange}[1]{#1}

Multi-arm manipulation teams combine complementary workspaces, end-effectors,
sensing, and payload capabilities. Their coordination becomes difficult when
the physical opportunity changes while the semantic objective is also allowed
to change. A target can move continuously on a conveyor, an external actor can
add, remove, or relocate an object, and a user can revise the task during
execution. These are distinct forms of runtime change: persistent physical
dynamics, exogenous scene changes, and online task updates. They should not be
treated as one undifferentiated dynamic-environment assumption.

Large language and vision-language models provide useful semantic capabilities
for interpreting instructions, grounding objects and skills, and revising task
state from feedback~\cite{huang2023inner,liang2023code,rana2023sayplan}. Such
reasoning is naturally event-driven, whereas perception, control, and target
motion continue between semantic events. A useful system therefore needs an
organization that keeps semantic authority coherent across heterogeneous arms
while allowing valid physical execution to evolve locally. This motivates the
question studied here: \emph{How should large-model semantic reasoning be
organized and invoked to coordinate heterogeneous multi-arm manipulation across
discrete semantic change and continuous physical evolution?}

\introchange{The resulting research gap is organizational rather than
model-internal. A heterogeneous team needs both explicit ownership of shared
semantic fields and a rule for deciding when a runtime change warrants
team-level semantic reconsideration rather than actuator-local adaptation.
Without these distinctions, semantic responsibility and execution validity are
not represented at their natural timescales.}

multi-arm conveyor workspace.

\subsection{Our Method}

\localexecchange{We address this gap with the two coupled components summarized
in Figure~\ref{fig:method_overview}. Role-Shared Semantic Coordination organizes
the Affordance, Planning, and Verification Roles over one authoritative,
versioned semantic state, with role-owned updates and capability-grounded
assignments. Multi-Timescale Semantic--Physical Coordination routes discrete
scene, task, and verification events to the responsible roles, selectively
reconsiders affected obligations, and allows still-valid actuator-local
execution to continue between events. The Semantic--Physical Interface names
only the boundary at which role-owned semantic commitments become bounded
Committed Execution Directives. Directive-governed actuator-local execution then
realizes each selected public skill from current visual observations and local
closed-loop control between semantic events.}

\begin{figure*}[t]
    \centering
    \includegraphics[width=\textwidth]{figures/figure2_final.pdf}
    \caption{Overview of the proposed coordination framework. Team-level
    Affordance, Planning, and Verification Roles update one authoritative
    semantic state and route typed events through a versioned transaction.
    \introchange{Committed execution directives connect that state to
    heterogeneous actuator-local executors, whose physical observations and
    local guards evolve between semantic events. Only event-level evidence
    returns upward for selective semantic re-entry.}}
    \label{fig:method_overview}
\end{figure*}

\introchange{The paper makes two contributions:}
\begin{itemize}
    \item \textbf{Role-Shared Semantic Coordination.}
    \introchange{We organize affordance interpretation, task planning, and
    semantic verification as team-level roles over one authoritative semantic
    state, give each semantic field a role-authorized owner, and ground
    assignments in heterogeneous actuator capabilities.}

    \item \textbf{Multi-Timescale Semantic--Physical Coordination.}
    \introchange{We distinguish discrete semantic events from continuous
    physical evolution, selectively reconsider only affected obligations, and
    allow valid actuator-local execution to continue between events under local
    observations and guards.}
\end{itemize}
